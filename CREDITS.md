# Credits

All application code (backend agents/pipeline, frontend screens, infrastructure templates,
tests) was written from scratch during the event window (17–20 Sept 2026, see `LEARNING.md` and
git history). Nothing here is a copied or adapted pre-existing project.

The build uses the following third-party, open-source packages as dependencies (not copied
code) — each under its own published licence:

## AWS services

Amplify Hosting, API Gateway, Lambda, DynamoDB, S3, Step Functions, SSM Parameter Store,
CloudWatch/Budgets — used under AWS's standard terms, not vendored code.

## External APIs

GitHub REST API, Hacker News (Algolia Search API), Tavily search/extract, App Store RSS,
Product Hunt GraphQL API — data retrieved live via each service's public API per its terms;
no scraped or vendored datasets are committed.

## Simulated data

PulseStack's own product feedback (support tickets, survey responses, churn notes) is
synthetic, generated by our own seeded simulator (`backend/simulator/`) from a documented
scenario file (`backend/simulator/scenario_pulsestack_v1.json`) — see PRD §8, `AGENTS.md`. It is not real
customer data and is always labelled `simulated` in the UI. Named competitors (Sentry, Datadog,
etc.) are real companies; only their own public reviews/discussions, retrieved live, are used —
no claim is invented on their behalf (§18).
